## X Premium Long Post

CueForge v0.2.0-alpha.6 is live for testers.

This update is about making the audio proof loop more real.

CueForge now has an audio export QA gate that can check generated Sound Match previews, learned EQ renders, stream/OBS checks, headset/IEM test tones, and voice/comms clips from one manifest.

The gate uses FFmpeg/ffprobe for metadata and a reusable Python loudness probe for LUFS, RMS, true peak, silence, stereo correlation, and channel distinctness. The important part: it reports derived JSON only. No raw audio gets embedded in reports.

## Reddit Helpful Comment

One practical thing I would check before trusting any FPS audio tweak is whether the result can be measured outside the app UI.

For CueForge I added an audio export QA gate that checks sample rate, bit depth, channel count, loudness, peak level, silence, stereo correlation, and simple channel distinctness. It is meant to catch problems like clipped stream audio, mono collapse, weird exports, or test clips that do not match the expected format.

The web app is here if it helps: https://p4nd4907.github.io/cueforge/

No pressure to use it. The main idea is still: prove the chain first, then tune.
