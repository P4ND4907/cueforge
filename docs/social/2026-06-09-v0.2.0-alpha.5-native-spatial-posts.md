## X Premium Long Post

CueForge v0.2.0-alpha.5 is live for testers.

This build tightens the main product loop:

1. Scan the setup
2. Check game audio settings
3. Run Sound Match
4. Get one safe recommendation
5. Apply only with proof, backup, and undo
6. Play a real match and report what changed

The new part I care about most is native spatial compatibility. Gaming audio is getting messier: Windows spatial, game HRTF, headset apps, Sonar, OEM APO layers, virtual mixers, OBS, Discord processing, and EQ can all stack without the player realizing it.

CueForge now checks for those layers before recommending changes. The goal is not to pretend one button magically fixes audio. The goal is to show what is active, what might conflict, and what the player should test next.

## Reddit Helpful Comment

If your FPS audio feels inconsistent, I would start by checking whether you have multiple processing layers active at the same time: game HRTF, Windows spatial, headset software, Sonar, EQ/APO, Discord processing, OBS filters, or a virtual mixer.

That stacking can make footsteps, center image, comms, and latency feel worse even when each individual tool sounds useful on its own.

I am building CueForge to make that chain easier to inspect. The web version is here if it helps: https://p4nd4907.github.io/cueforge/

No pressure to use it. The main idea is: prove the chain first, then tune.
